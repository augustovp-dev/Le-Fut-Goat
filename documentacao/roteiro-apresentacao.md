# Roteiro da Apresentação - Le' Fut Goat

Tempo sugerido: 5 a 7 minutos.

## Slide 1 - Capa

Fala:

```text
Meu projeto se chama Le' Fut Goat. Ele é um site sobre futebol que junta conteúdo informativo, minha história com o esporte e uma dashboard para montar uma carta de jogador no estilo FIFA.
```

## Slide 2 - Ideia do Projeto

Fala:

```text
A ideia veio da minha relação com o futebol. Eu queria fazer um projeto com um tema que fizesse sentido para mim e que também permitisse usar front-end, back-end, banco de dados e visualização de dados.
```

## Slide 3 - Objetivo

Fala:

```text
O objetivo foi criar uma aplicação simples e funcional. O usuário consegue navegar pelo site, conhecer o tema, criar uma conta, fazer login e usar uma dashboard para analisar atributos de jogador.
```

## Slide 4 - Tecnologias

Fala:

```text
Usei HTML, CSS e JavaScript no front-end. No back-end usei Node.js com Express. O banco de dados é MySQL e a visualização da dashboard usa Chart.js.
```

## Slide 5 - Estrutura

Fala:

```text
O projeto está separado em public, onde ficam as páginas, imagens e scripts do front-end, e src, onde ficam as rotas, controllers, models e configuração do banco.
```

## Slide 6 - Funcionalidades

Fala:

```text
As principais funcionalidades são a home, a página da minha história, cadastro, login e dashboard. O menu também muda conforme o usuário está logado ou não.
```

## Slide 7 - Dashboard

Fala:

```text
Na dashboard, o usuário informa ritmo, chute, passe, drible, defesa e físico. O sistema calcula o overall, mostra o desempenho por atributo e sugere uma posição ideal.
```

## Slide 8 - Banco de Dados

Fala:

```text
O banco guarda os usuários cadastrados. O login consulta os dados no MySQL e, quando encontra o usuário, salva as informações básicas na sessão do navegador.
```

## Slide 9 - Organização no Trello

Fala:

```text
Usei o Trello para organizar o andamento do projeto. Separei tarefas em backlog, a fazer, desenvolvimento, validação e concluído. Isso ajudou a controlar o que já estava pronto e o que precisava ser revisado.
```

## Slide 10 - Aprendizados e Próximos Passos

Fala:

```text
Com esse projeto, pratiquei integração entre front-end, back-end e banco de dados. Também aprendi a organizar melhor as funções e deixar o projeto mais simples de entender. Como próximos passos, eu criaria histórico de cartas, ranking e salvaria as análises dos usuários.
```

## Encerramento

Fala:

```text
Esse foi o Le' Fut Goat. Ele representa minha relação com o futebol e também mostra os principais conceitos que trabalhei durante o desenvolvimento.
```
